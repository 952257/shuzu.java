## 这个项目要做什么？

企业开发项目要从第三方系统把用户台账按时拉到本地：换 Token、分页拉用户、启动时同步一次、每天 03:00 再同步、增量写入 MySQL、Excel 上传 MinIO、按日期导出 Word。

企业运维项目是 MySQL 主从、Redis 哨兵、Nginx、Prometheus + Grafana，以及 EMP/DEPT SQL。

课题给的仓库：

- 基础工程：https://gitee.com/iocs/exam_demo.git
- 第三方：https://gitee.com/qwqweqwe/blade-springboot.git

## 四、Apifox 一键导入

1. 导入 `exam_demo/apifox/state-grid.postman_collection.json`

## 五、企业运维

文件在 `exam_demo/docker/` 和 `sql/ops-emp-dept.sql`。

这台 48GB / 14 核机器，VMware 已按性能改过：dorker专用 6GB/4核，其它演示机 2GB/2核。只开 Docker 专用机即可。

本机 3306 被占用，Compose 主从映射 3307/3308；Redis 映射 16379/16380。

```bash
colima start --cpu 4 --memory 8 --disk 40 --dns 8.8.8.8
export DOCKER_HOST=unix://$HOME/.colima/default/docker.sock
cd exam_demo/docker
sh up.sh
```

若拉镜像 DNS 失败：

```bash
colima ssh -- sudo rm -f /etc/resolv.conf
printf 'nameserver 8.8.8.8\nnameserver 223.5.5.5\n' | colima ssh -- sudo tee /etc/resolv.conf
```

Grafana：http://localhost:3000  `admin` / `127307`

## 六、常见问题

1. Apifox 返回 `{}`：环境选成了「本地 Mock」，改成「本地」。
2. Token 500 且堆栈是 `InaccessibleObjectException`：用 `mvn spring-boot:run`，pom 里已加 `--add-opens`。
3. JDK 25 启动失败：把 JAVA_HOME 指到 JDK 17。
