一、文档要你做什么
----------------

一共两份 Word，对应两块成绩：企业开发 + 企业运维。

【企业开发项目】本质是写一个 Spring Boot 对接程序（试卷给的基础工程 exam_demo，第三方是 Blade）：

1. 用 yml 里配置的租户、账号、密码、clientId/clientSecret，调用远程 OAuth：
   POST http://localhost/blade-auth/token
   Header: Authorization: Basic base64(saber:saber_secret)
           Content-Type: application/x-www-form-urlencoded
   参数: tenantId=000000  username=admin
         password=21232f297a57a5a743894a0e4a801fc3（这是 admin 的 MD5）
         grant_type=password  type=account  scope=all
   你自己要提供：GET /auth/token ，把拿到的 Token 返回给调用方。

2. 用 Token 里的 accessToken 调用户台账分页接口：
   GET http://localhost/blade-user/user-list?current=1&size=10
   Header 还要带 Blade-Auth: accessToken
   备注：isDeleted=1 表示逻辑删除。

3. 写定时任务：
   - 程序一启动立刻跑一次
   - 之后每天 03:00:00（Cron: 0 0 3 * * ?）再跑
   - 增量同步到本地 MySQL 表
   - 生成 Excel，上传到 MinIO

4. 日报导出：
   GET /report/export?date={date}
   返回 Word，格式类似：
       xxxx年 xx月 xx日 台账统计报告
       新增账户：_xx__个
       已删除账户：_xx__个
       某系统

开发交付物：源码 zip + 数据库 sql（只要结构）。本仓库 sql/schema.sql 就是结构文件。

【企业运维项目】本质是在 Linux 上把中间件搭起来，并写 SQL：

1. 安装 / 克隆 CentOS 7（本机是 Apple Silicon，说明见第七节）
2. 安装 Docker、Docker Compose
3. MySQL 主从同步热备份
4. Redis 哨兵模式集群
5. Nginx 反向代理 + 负载均衡
6. Prometheus + Grafana 监控 Spring Boot
7. 建 EMP / DEPT 表，插入数据，按题目写 SQL（已写在 sql/ops-emp-dept.sql）

运维交付物：四份安装文档 + SQL 脚本。本仓库 docs/ 目录就是这四份文档。

四、本机怎么跑（推荐，M4 直接用 Docker，不要开 CentOS 7 虚拟机）
----------------------------------------------------------

0. 安装 Docker Desktop（Apple Silicon 版），分配内存建议 6~8GB 就够。

1. 启动中间件：
     cd springboot/State-Grid/docker
     chmod +x up.sh mysql/setup-replication.sh
     ./up.sh
   或：docker compose up -d

2. IDEA 里启动两个 Spring Boot：
     blade-mock        端口 18080
     state-grid-app    端口 8080
   启动顺序：先 mock，再 app（app 启动时会立刻同步一次台账）。

3. 浏览器 / Apifox 验证：
     http://localhost:8080/auth/token
     http://localhost:8080/job/sync          （POST，手动再同步一次）
     http://localhost:8080/report/export?date=2026-09-04
     http://localhost:9001                    MinIO 控制台，bucket=demo
     http://localhost:9090                    Prometheus，应能看到 state-grid-app
     http://localhost:3000                    Grafana  admin / 127307

4. 验证 MySQL 主从：
     docker exec -it sg-mysql-slave mysql -uroot -p127307 -e "SHOW REPLICA STATUS\G"
     看 Replica_IO_Running、Replica_SQL_Running 都是 Yes。

5. 验证 Redis 哨兵：
     docker exec -it sg-redis-sentinel1 redis-cli -p 26379 SENTINEL masters

端口一览：
  80     Nginx（/blade-auth、/blade-user 转到 mock，其它转到 8080）
  8080   业务应用
  8081   第二实例（IDEA 加参数 --spring.profiles.active=replica，用来演示负载均衡）
  18080  blade-mock
  3306   MySQL 主    3307 MySQL 从     密码 127307
  6379   Redis 主    6380/6381 从      密码 127307
  26379/26380/26381  Redis 哨兵
  9000   MinIO API   9001 控制台
  9090   Prometheus  3000 Grafana

若要把业务也改成走 Nginx 80 端口（和试卷 URL 一致）：
  启动 app 时加 --spring.profiles.active=nginx
  此时 remote url 变成 http://127.0.0.1/blade-auth/token

六、增量同步怎么算「新增 / 已删除」
--------------------------------

本地表 local_user_ledger 以远程用户 id 为主键。

  远程有、本地没有           -> INSERT，新增 +1
  远程 isDeleted 从 0 变 1  -> UPDATE，已删除 +1
  其它字段变化              -> UPDATE，不计入新增/删除
  同一天多次同步            -> 当天日报累加本次增量（第一次启动会把 mock 里现有用户都算新增）

Excel：每次同步把当前全量表生成 xlsx，上传到 MinIO：
  demo/ledger/user-ledger-yyyy-MM-dd.xlsx


七、虚拟机还要不要开？按你这台电脑怎么配
------------------------------------

结论：交差、联调、截图，优先用上面的 Docker Compose。
你这台是 Apple M4 Pro（ARM）+ 48GB 内存，不是考试机常见的 Windows + VMware + CentOS 7 x86。

不要在 M4 上开 CentOS 7 x86 虚拟机：
  CentOS 7 官方只有 x86_64，UTM/VMware 走模拟会极慢，开 2~3 台基本没法用。

如果老师点名要「虚拟机 + Linux」截图，用 UTM 装 Rocky Linux 9 ARM
（yum/dnf、systemctl、docker 命令和 CentOS/RHEL 一套）：

  本机 48GB / 14 核，建议最多 2 台（不要 5 台）：

    名称        vCPU   内存    磁盘     装什么
    vm1-master   4     8 GB    40 GB    Docker、MySQL 主、Nginx、MinIO、
                                        Prometheus、Grafana、跑 Spring Boot
    vm2-node     2     6 GB    30 GB    Docker、MySQL 从、Redis 一主两从+三哨兵

  给 macOS + IDEA + Docker Desktop 至少留 16GB，所以两台虚拟机合计 14GB 很合适。
  48GB 理论上能开 3 台，第三台可以 2 核 4GB 只放监控，但没必要，监控放 vm1 即可。

  UTM 关键选项：
    - 虚拟化选 Apple Virtualization（不要选模拟 Intel）
    - 网络：共享网络（Shared）即可，两台能互相 ping
    - 假设 IP：vm1=192.168.64.10  vm2=192.168.64.11（以 UTM 实际为准）
    - root 密码：127307

  进虚拟机后：
    echo 127307 | passwd --stdin root     # 若发行版支持
    或直接 passwd 输入 127307
    关掉 firewalld / 或放行 3306 6379 80 9090 3000 9000
    安装 docker + docker compose 插件
    把本项目 docker/ 目录拷进去，把 nginx.conf 里的 host.docker.internal
    改成另一台的 IP 或改成容器名，再 docker compose up -d

  内存再紧时（例如同时开 IDEA）：
    把两台都减到 4GB，MySQL 容器 limit 降到 512M，Prometheus/Grafana 先不要在虚拟机里起，
    监控继续用 Mac 上的 Docker。本机 48GB 一般不需要这么缩。
