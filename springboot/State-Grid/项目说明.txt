国家电网数据平台 — 本机启动（不启虚拟机 / 不启 Docker）
====================================================

本次按你的要求：不启动 CentOS 虚拟机，也不后台起 Docker 集群。
只前台跑两个 Spring Boot 进程：

  blade-mock        18080   模拟第三方 OAuth + 用户台账
  state-grid-app    8080    业务程序（H2 文件库，Excel 写到 data/excel）

启动顺序：先 mock，再 app。
app 启动时会立刻同步一次台账；之后每天 03:00 再跑。

验证：
  curl -s http://127.0.0.1:8080/auth/token
  curl -s -X POST http://127.0.0.1:8080/job/sync
  curl -s "http://127.0.0.1:8080/report/stat?date=$(date +%F)"
  curl -L -o /tmp/report.docx "http://127.0.0.1:8080/report/export?date=$(date +%F)"

Apifox：
  业务接口 baseUrl = http://127.0.0.1:8080   （不要末尾斜杠，不要用 18080）
  mock 接口 mockUrl = http://127.0.0.1:18080
  导入 apifox/state-grid.postman_collection.json


H2 控制台（末尾斜杠不能省）：
  http://127.0.0.1:8080/h2-console/

登录（不要用默认的 jdbc:h2:~/test，那是空库）：
  JDBC URL:
    jdbc:h2:file:/workspace/springboot/State-Grid/state-grid-app/data/state_grid;MODE=MySQL;AUTO_SERVER=TRUE
  User Name: sa
  Password: （留空）
  点 Connect
  能看到 LOCAL_USER_LEDGER、SYNC_REPORT
