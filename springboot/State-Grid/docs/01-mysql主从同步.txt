MySQL 主从同步热备份（安装文档）
================================

适用：Docker 一键（推荐）或两台 Linux 虚拟机。
密码统一：root / 127307
本机已按 Mac M4 Pro 48GB 把容器内存限制在约 768MB/实例。

一、Docker 方式（本仓库已配好）
------------------------------

cd springboot/State-Grid/docker
docker compose up -d mysql-master mysql-slave mysql-replicator

主库 3306，从库 3307。首次启动会执行：
  docker/mysql/00-init-repl.sql   创建复制账号 repl / 127307
  sql/schema.sql                  业务库结构
  sql/ops-emp-dept.sql            运维 SQL 题

检查从库：
  docker exec -it sg-mysql-slave mysql -uroot -p127307 -e "SHOW REPLICA STATUS\G"
  Replica_IO_Running: Yes
  Replica_SQL_Running: Yes
  Seconds_Behind_Source: 0

验证同步：
  docker exec -it sg-mysql-master mysql -uroot -p127307 -e "CREATE DATABASE IF NOT EXISTS repl_test; USE repl_test; CREATE TABLE t(id INT); INSERT INTO t VALUES(1);"
  docker exec -it sg-mysql-slave  mysql -uroot -p127307 -e "SHOW DATABASES; SELECT * FROM repl_test.t;"

主库挂了从库仍可读（热备份）。恢复主库后 GTID 会自动追数据。

二、虚拟机手工方式（Rocky/CentOS，两台）
--------------------------------------

假设：
  主 192.168.64.10
  从 192.168.64.11
  root 密码 127307

两边都装 MySQL 8，配置文件要点：

主 /etc/my.cnf.d/master.cnf
  server-id=1
  log-bin=mysql-bin
  binlog-format=ROW
  gtid_mode=ON
  enforce_gtid_consistency=ON

从 /etc/my.cnf.d/slave.cnf
  server-id=2
  relay-log=relay-bin
  read_only=1
  gtid_mode=ON
  enforce_gtid_consistency=ON

主库执行：
  CREATE USER 'repl'@'%' IDENTIFIED WITH mysql_native_password BY '127307';
  GRANT REPLICATION SLAVE ON *.* TO 'repl'@'%';
  FLUSH PRIVILEGES;

从库执行：
  CHANGE REPLICATION SOURCE TO
    SOURCE_HOST='192.168.64.10',
    SOURCE_USER='repl',
    SOURCE_PASSWORD='127307',
    SOURCE_AUTO_POSITION=1;
  START REPLICA;
  SHOW REPLICA STATUS\G

业务程序只连主库 3306 写数据，从库 3307 作只读备份。

三、本机资源
------------

M4 Pro 48GB：Docker 里主从各限制 768MB，足够演示。
若放到虚拟机里，主库那台给 8GB，从库那台给 6GB（见 项目说明.txt 第七节）。
