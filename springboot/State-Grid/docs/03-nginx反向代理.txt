Nginx 反向代理负载均衡（安装文档）
==================================

一、本仓库配置在做什么
----------------------

文件：docker/nginx/nginx.conf

  /blade-auth/  /blade-user/  -> 宿主机 18080（blade-mock，第三方）
  其它请求                    -> 宿主机 8080（state-grid-app）
  8081 配成 backup，第二实例挂了不影响，起来后可分摊（least_conn）

启动：
  docker compose up -d nginx
  访问 http://127.0.0.1/auth/token     （需先启动两个 Spring Boot）
  访问 http://127.0.0.1/blade-auth/token  （需带 Basic 头，见 Apifox）

Mac Docker 用 host.docker.internal 访问宿主机进程。
Linux 虚拟机里 compose 已写 extra_hosts: host.docker.internal:host-gateway。

二、演示负载均衡
----------------

IDEA 再开一个 state-grid-app，VM options / Program arguments：
  --spring.profiles.active=replica
端口变成 8081。

连续访问：
  curl http://127.0.0.1/auth/token
Nginx access.log 里能看到转到 8080；把 8080 停掉后会打到 backup 8081。

三、虚拟机手工
--------------

yum/dnf install nginx
把 docker/nginx/nginx.conf 拷到 /etc/nginx/nginx.conf
把 host.docker.internal 改成应用所在 IP，例如 192.168.64.10:8080 和 :8081
systemctl enable --now nginx
firewall-cmd --add-port=80/tcp --permanent && firewall-cmd --reload

本机资源：Nginx 容器限制 64MB，可忽略。
