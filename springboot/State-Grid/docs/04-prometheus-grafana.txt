Prometheus + Grafana 监控 Spring Boot（安装文档）
================================================

一、应用侧（已写进 state-grid-app）
----------------------------------

依赖：
  spring-boot-starter-actuator
  micrometer-registry-prometheus

配置：
  management.endpoints.web.exposure.include: health,info,prometheus,metrics

验证：
  http://localhost:8080/actuator/health
  http://localhost:8080/actuator/prometheus
  页面里应能搜到 jvm_memory_used_bytes

二、Docker 方式
---------------

docker compose up -d prometheus grafana

Prometheus：http://127.0.0.1:9090
  Status -> Targets，job=state-grid-app 应为 UP
  查询：up{job="state-grid-app"}

Grafana：http://127.0.0.1:3000
  账号 admin / 127307
  已预置 Prometheus 数据源
  已预置看板「State-Grid SpringBoot」（JVM 堆内存、HTTP 耗时、应用是否在线）

也可再导入官方 JVM 看板（ID 4701）：
  Grafana -> Dashboards -> Import -> 4701 -> 选 Prometheus 数据源

三、Prometheus 抓取配置要点
--------------------------

docker/prometheus/prometheus.yml：

  scrape_interval: 5s
  job_name: state-grid-app
  metrics_path: /actuator/prometheus
  targets: host.docker.internal:8080 和 :8081

虚拟机里把 host.docker.internal 改成应用 IP。

四、资源
--------

Prometheus、Grafana 各限制 256MB。
本机 48GB 完全不用担心。
若只开一台 8GB 的虚拟机，这两个和 MySQL 主、Nginx、MinIO 可以放一起；
内存紧张时把 retention 保持 7 天即可，不要再加大。
